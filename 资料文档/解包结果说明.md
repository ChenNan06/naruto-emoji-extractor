# 火影忍者手游 表情包解包结果

## 一、核心成果：成功破解 KHFS 加密格式

火影手游的 AssetBundle 用的是自定义加密格式（非标准 UnityFS），所以 AssetStudio 打不开。
逆向结论：

- 文件头签名：`UnityKHFS` / `UnityKH1FS`（标准 UnityFS 签名里插入了 "KH"，头部版本=8）
- **只有「目录表」被加密**，资源数据块是**标准 LZ4（128KB 分块）**，完全没加密
- 破解方式：跳过加密目录 → 按 128KB 分块 LZ4 解压 → 得到标准 Unity SerializedFile → 交给 UnityPy

表情资源是 **Spine 3.8 骨骼动画**（86 骨骼、38 插槽、含加权网格 Mesh）。

## 三、关于静态表情（重要发现）

你问「安装包自带的表情少吗」——**是的**。基础 APK 里只有这 13 个**动态** Spine 表情。

静态表情不在 APK 里。证据：`assets/filelist.json` 写着游戏运行时会从服务器下载
`kihan.ifs`（228MB，地址 dlied5.qq.com/kihan/...），这就是主资源包（"KH" 即 "KiHan" 火影项目代号）。
静态表情、喷水(pengshui)等都在这个下载包里，格式是**另一种 IFS 容器**（不是 UnityFS）。

所以：
- 要拿静态表情，需要手机里游戏已下载的 `kihan.ifs` 文件（游戏数据目录里），或从该 URL 下载
- 拿到后我可以继续逆向 IFS 格式帮你提取

## 四、一体化工具

`火影解包器.py` —— 单文件程序，面向普通用户：

    python 火影解包器.py extract <bundle文件或目录> [-o 输出目录]    # 解包提取任意资源
    python 火影解包器.py emoji   <bundle目录>        [-o 输出目录]    # 提取所有表情+渲染GIF
    python 火影解包器.py render  <json> <atlas> <png> [-o 输出]      # 渲染单个Spine

游戏更新后，把新的 bundle 目录指给它，就能随时提取任意内容（贴图/文本/精灵/字体/表情）。
